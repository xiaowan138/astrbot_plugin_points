# astrbot_plugin_points · 群积分签到系统

> **注意：本插件目前为测试版（Beta），并非正式版，仍可能存在 bug。**
> 建议先在小范围群内试用，再决定是否用于正式群；大规模启用前请自行评估风险。

一个面向群聊的 AstrBot 4.x 玩法插件：每日签到领积分、连续签到加成、积分排行榜、积分抽奖（可自定义奖池）、积分商店兑换、每日任务、成就系统、周/月赛季榜、兑换核销与管理员审计，并内置 Web 管理面板。

## 功能

| 指令 | 说明 |
| --- | --- |
| `/签到` | 每日签到领取积分，连续签到有额外加成与里程碑奖励 |
| `/积分` | 查看积分与历史记录（累计获得/花费、最近流水） |
| `/积分流水 [页]` | 分页查看积分收支明细（每页 10 条，默认第 1 页） |
| `/签到日历` | 查看本月签到日历与连续签到天数 |
| `/任务` | 查看今日任务进度 |
| `/领取任务 签到\|发言\|抽奖` | 领取已完成任务的积分 |
| `/成就` | 查看成就列表与解锁进度 |
| `/我的背包` | 查看已兑换的物品 |
| `/排行榜 [N]` | 查看群内积分排行榜（优先图片） |
| `/周榜` / `/月榜` | 本周期新增积分榜（赛季榜） |
| `/抽奖` | 花费积分抽奖，可配置自定义奖池（默认随机积分 + 1% 三倍彩蛋） |
| `/商店` | 查看积分商店上架商品（图片卡片） |
| `/兑换 <编号> [数量]` | 使用积分兑换商品（需核销商品会生成兑换码） |
| `/赠送 @群友 数量` | 把积分转给群友 |
| `/积分帮助` | 查看指令帮助 |

> 管理员指令（群主/群管理员，或设置的"超级管理员"）：
> `/加积分 @用户 数量`、`/扣积分 @用户 数量`、`/设定积分 @用户 数量`（直接设为该值）、
> `/补签到 @用户`、`/重置用户 用户ID`、`/拉黑 @用户`、`/解除拉黑 @用户`、
> `/待核销`、`/核销 <兑换码>`、`/赛季结算 周|月`、`/审计日志`。
> 目标既可 `@` 也可直接填用户 ID。所有管理操作都会记入审计日志。
> 被拉黑的用户无法使用任何积分指令，也无法通过发言赚积分。

> 排行榜、个人积分与商店在安装 Pillow 且可找到中文字体时会输出为图片卡片，
> 否则自动降级为文本，不影响使用。

**Web 管理面板**（嵌入 AstrBot 仪表盘的插件页面）：
- 总览：用户数 / 总积分 / 今日签到 / 商品数 / 待核销 / 最近管理操作 / 一键导出备份
- 排行榜：查看全局或指定群的排行
- 用户管理：按关键词检索用户，支持加减积分、**精确改分（直接设为指定值）**、一键清理"0 积分且从未签到"的沉睡用户（先预览后确认）
- 商品管理：增删改积分商店商品（名称 / 描述 / 价格 / 库存 / 图标 / 是否需核销 / **上架与下架**）
- 抽奖奖池：自定义奖品、积分与权重，实时显示中奖概率
- 兑换核销：查看兑换记录并一键核销
- 审计日志：所有管理操作的回溯记录
- 设置：签到、抽奖（含保底）、任务、发言奖励、赛季（含自动结算与通胀回收）、提醒、时区、白名单、黑名单、面板权限、备份等全部配置

## 安装

1. 将本仓库放到 `AstrBot/data/plugins/astrbot_plugin_points/`
2. 重启 AstrBot（或热重载插件）
3. 在 AstrBot 插件详情页打开该插件的管理页面进行配置

> 数据保存在 AstrBot `data` 目录下的 `points_data.json`。若需图片卡片，运行
> `pip install Pillow` 即可（可选）。

## 配置说明（可在 Web 面板修改）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `signin_points` | 10 | 每次签到基础积分 |
| `streak_bonus_max` | 7 | 连续签到每日额外加成上限（第 2 天起每天 +1，最多 +7） |
| `lottery_cost` | 10 | 每次抽奖消耗积分 |
| `lottery_min` / `lottery_max` | 1 / 30 | 抽奖单次奖励区间 |
| `rank_top` | 10 | 排行榜默认展示人数 |
| `whitelist_groups` | 空 | 留空则不限制；填写群 ID 则仅这些群可用 |
| `use_image` | 开 | 是否将排行榜/积分输出为图片卡片（关闭则纯文本） |
| `font_path` | 空 | 图片卡片中文字体路径；留空自动探测系统字体 |
| `admin_user_ids` | 空 | 超级管理员用户 ID（逗号分隔）；留空则仅群主/管理员可用 |
| `lottery_daily_limit` | 0 | 每日抽奖次数上限，0=不限 |
| `milestone_rewards` | `{7:50, 30:300, 365:3650}` | 连续签到里程碑额外奖励，格式 `天数:积分` |
| `lottery_use_pool` | 关 | 开启后抽奖使用「奖池」标签页配置的加权奖品 |
| `allow_private` | 关 | 是否允许私聊使用积分系统（关闭可避免私聊/群积分分裂） |
| `timezone_offset` | 8 | UTC 偏移小时数，决定"今日签到"的日界 |
| `chat_reward_enabled` | 关 | 发言赚积分开关 |
| `chat_points_per_msg` / `chat_daily_points` | 1 / 20 | 每条发言积分 / 每日封顶 |
| `task_*` | 见面板 | 每日任务（签到/发言/抽奖）的达标条件与奖励 |
| `season_rewards` | `300,200,100` | 周/月榜结算时冠亚季军奖励 |
| `reminder_enabled` / `reminder_time` | 关 / 21:00 | 每日定时提醒未签到（依赖平台主动发消息能力） |
| `achievements_enabled` | 开 | 成就系统开关 |
| `achievement_broadcast` | 开 | 解锁成就时是否在回复中播报 |
| `rank_min_points` | 0 | 排行榜最低积分门槛，0=不过滤 |
| `lottery_pity` | 0 | 抽奖保底：连续 N 次未出最高奖励则下次必出，0=关闭 |
| `redemption_expire_days` | 0 | 兑换码有效期（天），0=不过期 |
| `season_auto_settle` / `season_settle_time` | 关 / 23:55 | 周日自动结周榜、月末自动结月榜 |
| `points_decay_percent` | 0 | 赛季结算后按比例回收积分（控制通胀），0=关闭 |
| `blacklist_user_ids` | 空 | 黑名单用户 ID，被拉黑者无法使用全部指令 |
| `panel_usernames` | 空 | 允许操作面板的 AstrBot 用户名，留空=任意已登录用户 |
| `auto_backup` | 开 | 启动时自动轮转备份数据文件（保留最近 7 份） |

## 图片卡片（可选）

在管理页"图片卡片"中可用开关控制是否以图片输出（默认开启）。安装 `Pillow` 后，
`/排行榜` 与 `/积分` 会输出为更清晰的图片卡片；未安装 Pillow 或系统缺少中文字体时，
自动回退为纯文本。若自动探测不到字体，可在"字体"栏填写具体字体文件路径
（如 Windows 的 `C:/Windows/Fonts/msyh.ttc`）。

## 白名单（可选）

在设置页的"群白名单"中填入一个或多个群 ID（英文逗号分隔）。留空表示所有群都启用。

## 数据说明

所有数据自动保存在 `AstrBot/data/points_data.json`（可在面板总览页一键导出备份）：
- `settings`：运行参数
- `users`：各群用户的积分、签到统计、任务/成就/赛季进度与兑换记录，键为 `群ID|用户ID`
- `products`：商店商品
- `prizes`：自定义抽奖奖池
- `redemptions`：兑换核销记录
- `audit_log`：管理员操作审计（保留最近 200 条）
- `seasons`：已归档的周/月赛季榜

为避免文件无限膨胀，各类历史列表都有保留上限（流水 50 条 / 购买 100 条 /
兑换 500 条 / 赛季 24 期）。开启 `auto_backup` 时，每次启动会在同目录的
`backup/` 下按天生成一份备份并只保留最近 7 份。

若数据文件彻底损坏无法解析，插件不会静默重置（那等于清空所有积分），
而是把原文件改名为 `points_data.json.corrupt-<时间戳>` 保留，再以空数据启动，
可在修复后手动恢复。删除 `points_data.json` 即可清空全部数据。

## 支持平台

- `aiocqhttp`（NapCat / Lagrange / LLOneBot 等 OneBot 实现）
- `qq_official`（QQ 官方机器人）

> **QQ 官方机器人说明**：受官方开放平台限制，无法直接读取群昵称，排行榜会以
> 成员 openid 显示；且需在管理端开启"@机器人 后回复"或用 `/` 触发，建议在
> 群内先发 `/积分帮助` 引导成员使用。

## 更新日志

### v1.2.2-beta（2026-09-25）

**修复**
- **数据文件损坏会清空全部用户积分**：解析失败时不再静默重置为默认数据，而是把原文件隔离为 `points_data.json.corrupt-<时间戳>` 后以空数据启动，可手动恢复；单条脏数据（如某商品库存是字符串）只跳过该条，不再拖垮整份数据
- **多群赛季结算互相串数据**：结算去重键由「周期」改为「周期 + 群」，各群榜单独立归档与发奖
- **周期切换后无法补结算**：榜单是懒惰清零的，管理员若忘了在切换前结算，旧榜单会被清空；现在周期切换瞬间会把旧榜单冻结成快照，支持事后补结算
- **「消费达人」成就可以被刷**：管理扣分与赠送他人积分会被计入 `total_spent`，导致可刷成就；成就判定改用真实消费口径（兑换/抽奖）
- **群内 `/核销` 报错且重复核销仍报成功**：核销结果改为区分「不存在 / 已核销 / 已过期 / 成功」，重复核销会明确提示
- **`/赠送` 给不存在的用户会凭空建档**：收款方必须已在本群注册，避免积分石沉大海
- **数据列表无上限膨胀**：流水 / 购买 / 兑换 / 赛季列表均加入保留上限
- 面板设置项在数据加载时也会做类型与范围校正，非法旧值不会让 `/任务` 等读路径抛异常
- 商品与奖池接口对非法数值（如 `cost: "abc"`）容错，不再 500

**新增**
- 数据自动备份：启动时按天在 `backup/` 生成备份并只保留最近 7 份（可关闭）
- 赛季自动结算：周日自动结周榜、月末自动结月榜（可配置检查时间）；结算后可按比例回收积分以控制通胀
- 抽奖保底：连续 N 次未出最高奖励则下次必出（开启奖池时按奖池最高奖品）
- 商品上架 / 下架：下架商品群内 `/商店` 不再展示、无法兑换，面板一键切换
- 兑换码有效期：超期自动失效并提示
- 用户黑名单：`/拉黑`、`/解除拉黑`，被拉黑者无法使用任何积分指令，也不计入发言积分
- 面板操作白名单：限制哪些 AstrBot 账号可以操作本插件面板
- 排行榜积分门槛：低于门槛的用户不进入榜单
- 精确改分：`/设定积分 @用户 数量` 直接把积分设为指定值；面板用户管理页也支持「改分」
- 沉睡用户清理：面板一键清理「0 积分且从未签到」的记录（先预览后确认）
- `/签到日历`：查看本月签到日历与连续天数
- `/积分流水 [页]`：分页查看积分收支明细
- 成就播报开关：可关闭解锁成就时的回复播报（成就本身仍会解锁）

**升级说明**：旧 `points_data.json` 自动迁移（补齐新字段、归一化库存与商品上架状态），无需手动处理；更新后请重启或热重载插件。

### v1.2.1-beta（2026-09-04）

**修复**
- 重复结算同一期周/月榜会向 0 分用户"凭空发奖"：同一周期只允许结算一次，且只有本期有积分产出的用户才参与排名与发奖；群内 `/赛季结算` 与面板结算都会得到明确提示
- 签到提醒可能因轮询漂移跳过目标分钟导致当天漏发：改为 30 秒轮询 + 2 分钟容忍窗口
- 管理员补签到不计连续签到天数，导致 7/30/365 里程碑被延后：补签现在与正常签到一致地累计连续天数，并按同样规则发放连续加成与里程碑奖励
- 赛季榜结算奖励未计入"累计获得"：结算发奖现与其他收入一致地进入累计统计与流水
- 未开启发言奖励时，群消息仍会为所有发言者创建用户记录，大群导致数据文件膨胀、排行榜出现大量 0 分用户：现在只为已注册用户计数（开启发言奖励后行为不变，任务进度同样只对已注册用户累计）
- 面板设置提交非法数值（如 "abc"）导致接口 500：非法值将被忽略并保留原值
- 管理员扣分超过用户余额时账目漂移（余额扣到 0 但按申请量记账）：现在按实际扣减量入账
- `/排行榜 N` 超过 20 人时图片卡片静默截断：现在显示"…还有 N 名未展示"提示
- 数据导出的时间戳改用插件配置时区，与其他记录保持一致
- 清理旧版本遗留在插件目录的 `img/*.png` 测试产物（运行时图片实际生成于数据目录）
