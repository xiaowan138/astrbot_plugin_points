# astrbot_plugin_points · 群积分签到系统

> **注意：本插件目前为测试版（Beta），并非正式版，仍可能存在 bug。**
> 建议先在小范围群内试用，再决定是否用于正式群；大规模启用前请自行评估风险。

一个面向群聊的 AstrBot 4.x 玩法插件：每日签到领积分、连续签到加成、积分排行榜、积分抽奖（可自定义奖池）、积分商店兑换、每日任务、成就系统、周/月赛季榜、兑换核销与管理员审计，并内置 Web 管理面板。

## 功能

| 指令 | 说明 |
| --- | --- |
| `/签到` | 每日签到领取积分，连续签到有额外加成与里程碑奖励 |
| `/积分` | 查看积分与历史记录（累计获得/花费、最近流水） |
| `/任务` | 查看今日任务进度 |
| `/领取任务 签到\|发言\|抽奖` | 领取已完成任务的积分 |
| `/成就` | 查看成就列表与解锁进度 |
| `/我的背包` | 查看已兑换的物品 |
| `/排行榜 [N]` | 查看群内积分排行榜（优先图片） |
| `/周榜` / `/月榜` | 本周期新增积分榜（赛季榜） |
| `/抽奖` | 花费积分抽奖，可配置自定义奖池（默认随机积分 + 1% 三倍彩蛋） |
| `/商店` | 查看积分商店上架商品（图片卡片） |
| `/兑换 <编号> [数量]` | 使用积分兑换商品（需核销商品会生成兑换码） |
| `/赠送 @群友 数量` | 把积分转给群友 |
| `/积分帮助` | 查看指令帮助 |

> 管理员指令（群主/群管理员，或设置的"超级管理员"）：
> `/加积分 @用户 数量`、`/扣积分 @用户 数量`、`/补签到 @用户`、`/重置用户 用户ID`、
> `/待核销`、`/核销 <兑换码>`、`/赛季结算 周|月`、`/审计日志`。
> 目标既可 `@` 也可直接填用户 ID。所有管理操作都会记入审计日志。

> 排行榜、个人积分与商店在安装 Pillow 且可找到中文字体时会输出为图片卡片，
> 否则自动降级为文本，不影响使用。

**Web 管理面板**（嵌入 AstrBot 仪表盘的插件页面）：
- 总览：用户数 / 总积分 / 今日签到 / 商品数 / 待核销 / 最近管理操作 / 一键导出备份
- 排行榜：查看全局或指定群的排行
- 用户管理：按关键词检索用户，支持加减积分
- 商品管理：增删改积分商店商品（名称 / 描述 / 价格 / 库存 / 图标 / 是否需核销）
- 抽奖奖池：自定义奖品、积分与权重，实时显示中奖概率
- 兑换核销：查看兑换记录并一键核销
- 审计日志：所有管理操作的回溯记录
- 设置：签到、抽奖、任务、发言奖励、赛季、提醒、时区、白名单等全部配置

## 安装

1. 将本仓库放到 `AstrBot/data/plugins/astrbot_plugin_points/`
2. 重启 AstrBot（或热重载插件）
3. 在 AstrBot 插件详情页打开该插件的管理页面进行配置

> 数据保存在 AstrBot `data` 目录下的 `points_data.json`。若需图片卡片，运行
> `pip install Pillow` 即可（可选）。

## 配置说明（可在 Web 面板修改）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `signin_points` | 10 | 每次签到基础积分 |
| `streak_bonus_max` | 7 | 连续签到每日额外加成上限（第 2 天起每天 +1，最多 +7） |
| `lottery_cost` | 10 | 每次抽奖消耗积分 |
| `lottery_min` / `lottery_max` | 1 / 30 | 抽奖单次奖励区间 |
| `rank_top` | 10 | 排行榜默认展示人数 |
| `whitelist_groups` | 空 | 留空则不限制；填写群 ID 则仅这些群可用 |
| `use_image` | 开 | 是否将排行榜/积分输出为图片卡片（关闭则纯文本） |
| `font_path` | 空 | 图片卡片中文字体路径；留空自动探测系统字体 |
| `admin_user_ids` | 空 | 超级管理员用户 ID（逗号分隔）；留空则仅群主/管理员可用 |
| `lottery_daily_limit` | 0 | 每日抽奖次数上限，0=不限 |
| `milestone_rewards` | `{7:50, 30:300, 365:3650}` | 连续签到里程碑额外奖励，格式 `天数:积分` |
| `lottery_use_pool` | 关 | 开启后抽奖使用「奖池」标签页配置的加权奖品 |
| `allow_private` | 关 | 是否允许私聊使用积分系统（关闭可避免私聊/群积分分裂） |
| `timezone_offset` | 8 | UTC 偏移小时数，决定"今日签到"的日界 |
| `chat_reward_enabled` | 关 | 发言赚积分开关 |
| `chat_points_per_msg` / `chat_daily_points` | 1 / 20 | 每条发言积分 / 每日封顶 |
| `task_*` | 见面板 | 每日任务（签到/发言/抽奖）的达标条件与奖励 |
| `season_rewards` | `300,200,100` | 周/月榜结算时冠亚季军奖励 |
| `reminder_enabled` / `reminder_time` | 关 / 21:00 | 每日定时提醒未签到（依赖平台主动发消息能力） |
| `achievements_enabled` | 开 | 成就系统开关 |

## 图片卡片（可选）

在管理页"图片卡片"中可用开关控制是否以图片输出（默认开启）。安装 `Pillow` 后，
`/排行榜` 与 `/积分` 会输出为更清晰的图片卡片；未安装 Pillow 或系统缺少中文字体时，
自动回退为纯文本。若自动探测不到字体，可在"字体"栏填写具体字体文件路径
（如 Windows 的 `C:/Windows/Fonts/msyh.ttc`）。

## 白名单（可选）

在设置页的"群白名单"中填入一个或多个群 ID（英文逗号分隔）。留空表示所有群都启用。

## 数据说明

所有数据自动保存在 `AstrBot/data/points_data.json`（可在面板总览页一键导出备份）：
- `settings`：运行参数
- `users`：各群用户的积分、签到统计、任务/成就/赛季进度与兑换记录，键为 `群ID|用户ID`
- `products`：商店商品
- `prizes`：自定义抽奖奖池
- `redemptions`：兑换核销记录
- `audit_log`：管理员操作审计（保留最近 200 条）
- `seasons`：已归档的周/月赛季榜

删除该文件即可清空全部数据（插件会重新初始化默认值）。

## 支持平台

- `aiocqhttp`（NapCat / Lagrange / LLOneBot 等 OneBot 实现）
- `qq_official`（QQ 官方机器人）

> **QQ 官方机器人说明**：受官方开放平台限制，无法直接读取群昵称，排行榜会以
> 成员 openid 显示；且需在管理端开启"@机器人 后回复"或用 `/` 触发，建议在
> 群内先发 `/积分帮助` 引导成员使用。

## 更新日志

### v1.2.0-beta（2026-08-29）

**修复**
- 多群同时查看排行榜/积分时图片互相覆盖：渲染文件名改为唯一随机后缀，旧图自动清理
- `/兑换 <编号> 两` 等非整数数量导致指令报错：改为容错解析并友好提示
- 管理员补签到时，目标当日已签到仍会记一笔未实际发放的积分流水（账实不符）
- 私聊签到产生"私聊积分与群积分互不相通"的困惑：新增 `allow_private` 开关（默认关闭）
- 部署在 UTC 时区容器时签到日界错位：新增 `timezone_offset` 配置（默认 +8）
- 个人积分卡第四列数值在长数字下被裁切；旧数据中字符串 `-1` 库存显示矛盾；抽奖区间 min>max 未校验

**新增**
- 每日任务系统：`/任务` 查看进度、`/领取任务 签到|发言|抽奖` 领取奖励
- 发言赚积分：群消息自动计分，每条/每日封顶可配（默认关闭）
- 周/月赛季榜：`/周榜` `/月榜` 按本期新增积分排名；管理员 `/赛季结算 周|月` 归档并发冠亚季奖励
- 兑换核销闭环：商品可标记"需核销"，兑换生成兑换码，`/待核销` `/核销 <兑换码>` 完成闭环
- 管理员审计日志：群内与面板的全部管理操作留痕，`/审计日志` 可查
- 每日定时签到提醒（默认关闭，依赖平台主动发消息能力）
- 自定义抽奖奖池：面板配置奖品/积分/权重，实时显示中奖概率
- 成就系统：8 个成就自动解锁并发积分，`/成就` 查看
- 商店图片卡片：`/商店` 输出图片（自动降级文本）
- 面板一键导出数据备份（JSON）；面板新增「抽奖奖池 / 兑换核销 / 审计日志」标签页

**升级说明**：旧 `points_data.json` 自动迁移（补齐新字段、归一化库存），无需手动处理；更新后请重启或热重载插件。
