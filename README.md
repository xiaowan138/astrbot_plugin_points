# astrbot_plugin_points · 群积分签到系统

> **注意：本插件目前为测试版（Beta），并非正式版，仍可能存在 bug。**
> 建议先在小范围群内试用，再决定是否用于正式群；大规模启用前请自行评估风险。

一个面向群聊的 AstrBot 4.x 玩法插件：每日签到领积分、连续签到加成、积分排行榜、积分抽奖、积分商店兑换，并内置 Web 管理面板。

## 功能

| 指令 | 说明 |
| --- | --- |
| `/签到` | 每日签到领取积分，连续签到有额外加成 |
| `/积分` | 查看积分与历史记录（累计获得/花费、最近流水） |
| `/我的背包` | 查看已兑换的物品 |
| `/排行榜 [N]` | 查看群内积分排行榜（优先图片） |
| `/抽奖` | 花费积分抽奖，有 1% 概率触发三倍彩蛋 |
| `/商店` | 查看积分商店上架商品 |
| `/兑换 <编号> [数量]` | 使用积分兑换商品 |
| `/积分帮助` | 查看指令帮助 |

> 排行榜与个人积分在安装 Pillow 且可找到中文字体时会输出为图片卡片，
> 否则自动降级为文本，不影响使用。

**Web 管理面板**（嵌入 AstrBot 仪表盘的插件页面）：
- 总览：用户数 / 总积分 / 今日签到 / 商品数
- 排行榜：查看全局或指定群的排行
- 用户管理：按关键词检索用户，支持加减积分
- 商品管理：增删改积分商店商品（名称 / 描述 / 价格 / 库存 / 图标）
- 设置：签到积分、连续签到加成上限、抽奖消耗与奖励区间、排行榜展示人数、群白名单

## 安装

1. 将本仓库放到 `AstrBot/data/plugins/astrbot_plugin_points/`
2. 重启 AstrBot（或热重载插件）
3. 在 AstrBot 插件详情页打开该插件的管理页面进行配置

> 数据保存在 AstrBot `data` 目录下的 `points_data.json`。若需图片卡片，运行
> `pip install Pillow` 即可（可选）。

## 配置说明（可在 Web 面板修改）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `signin_points` | 10 | 每次签到基础积分 |
| `streak_bonus_max` | 7 | 连续签到每日额外加成上限（第 2 天起每天 +1，最多 +7） |
| `lottery_cost` | 10 | 每次抽奖消耗积分 |
| `lottery_min` / `lottery_max` | 1 / 30 | 抽奖单次奖励区间 |
| `rank_top` | 10 | 排行榜默认展示人数 |
| `whitelist_groups` | 空 | 留空则不限制；填写群 ID 则仅这些群可用 |
| `use_image` | 开 | 是否将排行榜/积分输出为图片卡片（关闭则纯文本） |
| `font_path` | 空 | 图片卡片中文字体路径；留空自动探测系统字体 |

## 图片卡片（可选）

在管理页"图片卡片"中可用开关控制是否以图片输出（默认开启）。安装 `Pillow` 后，
`/排行榜` 与 `/积分` 会输出为更清晰的图片卡片；未安装 Pillow 或系统缺少中文字体时，
自动回退为纯文本。若自动探测不到字体，可在"字体"栏填写具体字体文件路径
（如 Windows 的 `C:/Windows/Fonts/msyh.ttc`）。

## 白名单（可选）

在设置页的"群白名单"中填入一个或多个群 ID（英文逗号分隔）。留空表示所有群都启用。

## 数据说明

所有数据自动保存在 `AstrBot/data/points_data.json`：
- `settings`：运行参数
- `users`：各群用户的积分、签到统计与兑换记录，键为 `群ID|用户ID`
- `products`：商店商品

删除该文件即可清空全部数据（插件会重新初始化默认值）。

## 支持平台

- `aiocqhttp`（NapCat / Lagrange / LLOneBot 等 OneBot 实现）
- `qq_official`（QQ 官方机器人）

> **QQ 官方机器人说明**：受官方开放平台限制，无法直接读取群昵称，排行榜会以
> 成员 openid 显示；且需在管理端开启"@机器人 后回复"或用 `/` 触发，建议在
> 群内先发 `/积分帮助` 引导成员使用。
